# 🎮 Number Guessing Game

My first C# console application!

## 📌 About the Project

Number Guessing Game is a simple console-based game developed using C#.

The computer generates a random number between 1 and 100, and the player must guess the correct number.

The game provides hints to help the player:
- **Too low!** – Your guess is lower than the secret number.
- **Too high!** – Your guess is higher than the secret number.
- **Correct!** – You've guessed the right number!

## 🚀 Features

- Random number generation
- Interactive console gameplay
- Input validation
- Attempt counter
- Replay functionality

## 🛠️ Technologies Used

- C#
- .NET
- Visual Studio 2022

## 📋 Requirements

- Windows
- .NET SDK

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open the `.csproj` file using Visual Studio 2022.

Alternatively, open a terminal in the project directory and run:

```bash
dotnet run
```
